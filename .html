Python Checkout Replay Script Guide

The application includes a backend Python 3 replay script (replay_checkout.py) implementing the Stretch Goal requirements:

  • Sequentially loads transactions and tests inventory stock availability before processing.
  • Enforces non-negative stock invariant using Python assertions: assert product["stock"] >= 0.
  • Rejects transactions exceeding inventory without modifying stock, then outputs a full audit summary table.
How to Execute in Terminal:
# Navigate to project directory
cd "OJT project"

# Run the sequential replay engine
python3 replay_checkout.py
The script reads from sample-data.json, executes 5 sequential transactions (including intentional oversell attempts), and verifies that all assertions pass cleanly.
Reset Store Data?

This will reset all inventory items and checkout transaction records back to the official sample data (P001 to P004) defined in sample-data.json.

Local storage keys campus_store_products and campus_store_transactions will be restored to their baseline state.
